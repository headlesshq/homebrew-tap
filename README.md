# HeadlessHQ Tap

[Homebrew](https://brew.sh) tap for [HeadlessMc](https://github.com/headlesshq/headlessmc),
a command line launcher for Minecraft Java Edition. Works on macOS and Linux (x64 and ARM64).

## Install

```shell
brew install headlesshq/tap/headlessmc
headlessmc --version
```

Or `brew tap headlesshq/tap` and then `brew install headlessmc`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "headlesshq/tap"
brew "headlessmc"
```

Update with `brew upgrade headlessmc`.

## How releases get here

`Formula/headlessmc.rb` is generated by [`.github/scripts/update-headlessmc.sh`](.github/scripts/update-headlessmc.sh)
from the native executables of a HeadlessMc GitHub release.
The [Update headlessmc](.github/workflows/update-headlessmc.yml) workflow runs the script, audits, installs and tests
the formula and pushes it to `main`. It runs

- when the release job of headlesshq/headlessmc sends a `headlessmc-release` repository dispatch,
- daily, as a fallback,
- manually, optionally for a specific tag.

To update locally: `.github/scripts/update-headlessmc.sh [tag]`.
